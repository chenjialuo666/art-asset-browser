# 美术资源管理器

Unity 编辑器本地资源浏览工具。本仓库仅提供发行文件和下载说明，不包含工具源码或项目美术资源。

## 下载

[查看最新版本及更新说明](https://github.com/chenjialuo666/art-asset-browser/releases/latest)

[下载 V0.7.4 安装包](https://github.com/chenjialuo666/art-asset-browser/releases/download/v0.7.4/ArtAssetBrowser-0.7.4-installer.zip)

## 安装和使用

1. 解压安装包，运行 `ArtAssetBrowserInstaller.exe`，选择需要使用工具的 Unity 项目。
2. 默认安装位置为项目内 `Assets/Editor/com.artasset.browser`。
3. 在 Unity 菜单中打开 `Art Tools / 美术资源管理器`。
4. 后续在管理器内检查更新和卸载，无需每次重新下载安装包。

首次安装使用安装包；更新包、维护组件包及 `update.json` 供工具读取，不需要手动覆盖。

## 验证范围

- 当前验证环境：Windows x64、Unity 2022.3.62f2c1。
- 其它 Unity 版本、超长项目路径未完成验收，不宣称兼容。
- 工具在本地运行；联网检查更新不等于上传项目资源。
- V0.7.4 为首个公开试用基线。未来版本的自动提示与实际替换，需在有真实新版后继续实网验证；不把“已是最新版”当作完整升级验收。
