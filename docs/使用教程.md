# 美术资源管理器使用教程

内容版本：V0.7.7

从资源浏览、筛选和收藏，到模型检查、引用查询、组合导出及更新维护。工具默认在本机使用，不会因为检查更新而上传项目美术资源。

> 请以实际安装版本为准。教程入口随包含该功能的版本提供；旧版没有入口时，可从GitHub首页阅读本教程。

## 1. 安装与打开

![1. 安装与打开操作示意](images/start.png)

*操作示意，非真实项目截图。*

1. 首次使用：从GitHub仓库首页下载标明Windows安装包的ZIP，解压后运行ArtAssetBrowserInstaller.exe。
2. 在安装管理器中选择Unity项目，核对预览后安装。默认程序目录为Assets/Editor/com.artasset.browser。
3. 进入Unity后，从Art Tools / 美术资源管理器打开工具。
4. 有使用教程按钮的版本，可直接从管理器打开本地HTML；首次打开会从工具内置内容生成，不需要联网。

> 不要把GitHub自动生成的Source code压缩包当成安装包。

> 已安装用户通常直接在管理器内更新，无需重复运行安装包。

## 2. 资源浏览与筛选

![2. 资源浏览与筛选操作示意](images/browse.png)

*操作示意，非真实项目截图。*

1. 先选择Assets下要浏览的目录。全部、预制体、模型、贴图、材质、场景用于切换资源类型。
2. 左键点击类型按钮进行单选；右键用于组合选择多个类型。
3. 在搜索框输入资源名称或路径关键词；多个词以空格分开时，需要同时匹配。
4. 通过分类和子类缩小目录范围，中文显示用于辅助理解目录含义，不会重命名项目文件。
5. 用列表底部的尺寸滑块调整缩略图大小。定位用于在项目中找到资源，资源器用于打开文件所在位置。

> 搜索只筛选已建立的资源列表。新增或变更资源未显示时，可点击刷新。

> 重建资源列表与重建引用索引不是同一个操作。

## 3. 最近搜索与收藏

![3. 最近搜索与收藏操作示意](images/history.png)

*操作示意，非真实项目截图。*

1. 搜索后按Enter或离开搜索框，关键词会记录到历史菜单，最多保留最近10条。
2. 点击历史条目可以重新筛选；重复关键词会前移，空关键词不会记录。清空搜索历史只清除历史，不删除任何资源。
3. 点击资源卡片上的星号收藏或取消收藏。收藏资源在正常列表中置顶，但仍是同一个资源，不会复制资源文件。
4. 顶部星号筛选用于只看收藏资源。收藏不会让资源绕过当前目录、类型和搜索条件。

> 搜索历史和收藏保存到本机数据目录。

> 不要把收藏置顶理解为把资源复制到另一个文件夹。

## 4. 放大预览与看不见的模型

![4. 放大预览与看不见的模型操作示意](images/preview.png)

*操作示意，非真实项目截图。*

1. 选中资源后，在资源详情中双击预览图，或点击放大按钮，打开独立预览。
2. 模型预览提供材质、结构、线框、法线模式。材质用于查看原材质；结构用于辨认几何；线框用于检查三角形结构。
3. 法线模式显示世界空间顶点法线，不是法线贴图预览。
4. 很薄的草片、边界面或单面模型不明显时，可尝试结构模式、双面选项及重置视角。双面只影响临时预览，不会修改原材质。
5. 贴图也可单独放大查看。切换资源时预览会跟随选择，不必反复打开多个窗口。

> 空预览不一定表示资源丢失，也可能与单面朝向、材质、自定义Shader、网格或视角有关。

> 烘焙、导入、编译或游戏运行时，诊断预览可能暂停；某些设备不支持线框预览。

> 预览不执行资源脚本或动画，不自动保存场景或修改导入设置。

## 5. 模型、LOD与资源检查

![5. 模型、LOD与资源检查操作示意](images/checks.png)

*操作示意，非真实项目截图。*

1. 在详情里查看三角面、顶点、Mesh、Renderer和材质槽等统计。
2. 展开LOD检查查看LODGroup相关信息。没有LODGroup表示未发现该组件，不等于模型无法使用。
3. 引用查询页中的资源检查可按当前资源或浏览目录运行检查，查看结果后再决定如何处理。

> 检查结果用于辅助排查，不会自动修复、删除或重新命名你的资源。

## 6. 引用来源、资源依赖与场景内查

![6. 引用来源、资源依赖与场景内查操作示意](images/references.png)

*操作示意，非真实项目截图。*

1. 引用来源：查看哪些资源引用了当前资源，可用于判断它是否被Prefab、场景或其他资产使用。
2. 资源依赖：查看当前资源依赖哪些资产，例如预制体引用的模型、材质或贴图。
3. 场景内查：检查已经打开并加载的场景，不会自动打开所有场景。
4. 需要基于项目文件查询时，先确认扫描范围并建立引用索引。范围或资源变化后，按提示更新索引。
5. 索引结果不完整时再考虑深度扫描；扫描范围越大，耗时越长。

> 引用索引是本机缓存快照，不是项目实时真相；未建索引或索引过期时不能据此断言资源无人使用。

## 7. 拖入Unity场景

![7. 拖入Unity场景操作示意](images/drag.png)

*操作示意，非真实项目截图。*

1. 从资源卡片拖动可支持的模型或预制体，放到Unity场景或Hierarchy中。
2. 材质球可拖放到适合接收材质的对象或位置；具体放置由Unity原生拖放处理。
3. 如果没有产生预期效果，先检查拖放目标、资源类型和Unity当前是否正在编译、导入或运行。

> 工具不会自动替你保存场景。完成编辑后按自己的工作流程保存。

## 8. 多选与组合打包导出

![8. 多选与组合打包导出操作示意](images/export.png)

*操作示意，非真实项目截图。*

1. 在资源列表选择一个或多个要导出的资源，右键打开导出菜单。
2. 在导出窗口核对所选资源，并选择是否收集相关模型、贴图引用。选择预制体时，可以收集它实际用到的相关模型与贴图。
3. 选择输出位置并自定义打包文件夹名；同一批选择组合到一个输出文件夹，不保留冗长的原目录层级。
4. 确认预览后执行导出。模型与贴图原名保持不变；遇到重名或其他阻挡提示时先核对，不要强行覆盖。

> 该功能用于快捷收集模型与贴图，不是完整Unity工程迁移。

> 当前不把材质球、Shader及脚本作为完整项目打包导出，也不能承诺在其他软件中还原Unity材质效果。

## 9. 更新、卸载与版本控制

![9. 更新、卸载与版本控制操作示意](images/maintenance.png)

*操作示意，非真实项目截图。*

1. 点击更新记录查看版本变化；点击检查更新获取公开版本信息，确认说明后再下载并更新。
2. 如提示等待Unity关闭，请先保存工作并正常关闭目标Unity，完成后重新打开项目。不要手动覆盖安装目录。
3. 卸载工具入口会先给出操作预览。核对将移除和保留的内容，再确认卸载。
4. Git / UGit与SVN分别设置。先看预览和提示，确认后才应用支持的修改；以界面显示的真实检测状态为准。

> 工具默认本机使用，不等于自动提交或上传到Git、UGit、SVN。已经被版本控制跟踪的文件不能靠忽略规则自动撤回。

> 没有仓库、缺少客户端或无法验证时，不应把开关显示当成已经配置成功。

> 检查更新仅读取公开发行信息，不上传你的美术资源。

## 10. 本机数据与常见问题

![10. 本机数据与常见问题操作示意](images/data.png)

*操作示意，非真实项目截图。*

1. 收藏、历史、索引、预览缓存等本机数据集中保存在安装目录下的LocalData~，与程序文件分开管理。
2. 如果预览异常，先确认资源和导入状态，再刷新或按工具提供的方式处理缓存；不要直接删除整个Unity项目Library。
3. 本地教程在LocalData~/Documentation下生成。更新到包含新教程内容的版本后，再次打开会使用随程序携带的新内容。
4. 反馈问题时提供工具版本、Unity版本、操作步骤及错误信息，不要上传凭据或未经授权的项目资源。

> 缓存用于减少重复扫描和预览生成，不是资源文件的替代备份。

> 当前已验证Windows x64、Unity2022.3.62f2c1；其他Unity版本、渲染管线或特殊项目设置仍需实际验证。
